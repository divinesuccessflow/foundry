# Launch Checklist

**Don't miss critical steps. Use this checklist for every launch.**

---

## 🚀 The 3 Phases of a Successful Launch

1. **PRE-LAUNCH** (2-4 weeks before) - Build anticipation, validate, prepare
2. **LAUNCH** (Launch week) - Execute, sell, deliver
3. **POST-LAUNCH** (2 weeks after) - Optimize, follow up, iterate

---

## 📅 PRE-LAUNCH PHASE (4 Weeks Out)

### WEEK 1: FOUNDATION & VALIDATION

#### Product/Offer
- [ ] Define exactly what you're launching (product, service, course, etc.)
- [ ] Write a clear one-sentence description
- [ ] Determine pricing (see Pricing Strategy Calculator)
- [ ] Create 3 tiers if applicable (good, better, best)
- [ ] Set launch goal (# of customers, $ revenue)
- [ ] Validate with 5-10 target customers (surveys, interviews)

#### Positioning & Messaging
- [ ] Define your target customer (see Customer Avatar Worksheet)
- [ ] Identify the core problem you solve
- [ ] Craft your value proposition (why you vs. competitors)
- [ ] Write your elevator pitch (30 seconds)
- [ ] Identify 3-5 key benefits (not features)
- [ ] Create urgency/scarcity angle (limited spots, early bird, deadline)

#### Technical Setup
- [ ] Choose your platform (website, landing page, course platform)
- [ ] Set up payment processing (Stripe, PayPal, Gumroad)
- [ ] Create landing page / sales page
- [ ] Set up email automation (welcome sequence, nurture, sales)
- [ ] Test checkout flow end-to-end (mobile + desktop)
- [ ] Set up analytics (Google Analytics, Facebook Pixel, etc.)

**MILESTONE:** ✅ Validated offer + Sales page drafted + Tech stack ready

---

### WEEK 2: CONTENT & ASSETS

#### Sales Page / Landing Page
- [ ] Write compelling headline (address pain point)
- [ ] Write persuasive copy (problem → solution → benefits → social proof → CTA)
- [ ] Add 5-10 testimonials or case studies (if you have them)
- [ ] Create FAQ section (address objections)
- [ ] Include clear CTA (call-to-action) buttons throughout
- [ ] Add guarantee / refund policy (reduce risk)
- [ ] Mobile-optimize the entire page

#### Visuals & Design
- [ ] Create product images / mockups
- [ ] Design social media graphics (5-10 templates)
- [ ] Create video (explainer, demo, testimonial)
- [ ] Design email headers / banners
- [ ] Create countdown timer graphics
- [ ] Prepare GIFs / animations for social

#### Lead Magnet / Pre-Launch Offer
- [ ] Create free lead magnet (checklist, template, mini-course)
- [ ] Set up opt-in page
- [ ] Write email sequence for leads (3-5 emails before launch)
- [ ] Offer early bird pricing or bonus for pre-launch signups

**MILESTONE:** ✅ Sales page live + Assets created + Lead magnet ready

---

### WEEK 3: AUDIENCE BUILDING & BUZZ

#### Email List
- [ ] Clean your email list (remove inactive subscribers)
- [ ] Segment list (hot leads, warm leads, cold leads)
- [ ] Write pre-launch email sequence (1 email every 2-3 days)
- [ ] Tease the launch (hint at what's coming)
- [ ] Build anticipation with sneak peeks

#### Content Marketing
- [ ] Publish 3-5 blog posts related to the problem you solve
- [ ] Create 5-7 social media posts (teasers, behind-the-scenes)
- [ ] Record 1-2 YouTube videos (value-first, not promotional)
- [ ] Appear on 1-2 podcasts / guest posts (if possible)
- [ ] Start daily Instagram Stories / Twitter threads

#### Partnerships & Affiliates
- [ ] Identify 5-10 potential affiliate partners
- [ ] Reach out with affiliate proposal (what's in it for them)
- [ ] Set up affiliate tracking links
- [ ] Provide affiliates with promotional materials
- [ ] Schedule affiliate emails / posts for launch day

#### Community & Social Proof
- [ ] Engage in relevant communities (Reddit, Facebook groups, forums)
- [ ] Offer free value (without pitching yet)
- [ ] Collect testimonials from beta users / early testers
- [ ] Create case studies from early wins
- [ ] Screenshot positive feedback for social proof

**MILESTONE:** ✅ Built anticipation + Email list primed + Partnerships secured

---

### WEEK 4: FINAL PREP & DRY RUN

#### Test Everything
- [ ] Test checkout process (credit card, PayPal, etc.)
- [ ] Test email automations (trigger each sequence)
- [ ] Test all links on sales page
- [ ] Test mobile experience
- [ ] Review all copy for typos / errors
- [ ] Test discount codes / coupons (if using)
- [ ] Ensure analytics/tracking is working

#### Launch Day Prep
- [ ] Schedule launch emails (time-zone optimized)
- [ ] Schedule social media posts (all platforms)
- [ ] Prepare FAQs / support responses
- [ ] Set up customer support system (email, chat, etc.)
- [ ] Prepare "sold out" / "waitlist" messaging (if limited inventory)
- [ ] Clear your calendar for launch day (be available)

#### Team Alignment (if applicable)
- [ ] Brief your team on launch plan
- [ ] Assign roles (who handles support, who monitors social, etc.)
- [ ] Set up communication channel (Slack, WhatsApp group)
- [ ] Schedule check-in times during launch

#### Final Hype
- [ ] Send "24 hours until launch" email
- [ ] Post countdown on social media
- [ ] Go live / host Q&A session
- [ ] Tease final bonuses or early bird perks

**MILESTONE:** ✅ Everything tested + Team ready + Launch imminent

---

## 🎉 LAUNCH PHASE (Launch Week)

### LAUNCH DAY (Day 1)

#### Morning (8-10am)
- [ ] Send launch email to entire list
- [ ] Post on all social media platforms
- [ ] Update website homepage with launch announcement
- [ ] Pin launch post on Twitter / Instagram
- [ ] Text/DM close contacts personally
- [ ] Go live on Instagram / YouTube for Q&A

#### Midday (11am-2pm)
- [ ] Monitor sales / conversions
- [ ] Reply to all comments / messages
- [ ] Share early results ("10 sold in first hour!")
- [ ] Post customer testimonials as they come in
- [ ] Address common objections in real-time posts

#### Evening (5-8pm)
- [ ] Send "Day 1 Recap" email
- [ ] Post behind-the-scenes / celebration content
- [ ] Thank early customers publicly
- [ ] Share scarcity reminder ("50% of spots gone!")
- [ ] Schedule tomorrow's content

#### Night (Before bed)
- [ ] Review analytics (traffic, conversions, revenue)
- [ ] Note what worked / what didn't
- [ ] Adjust tomorrow's strategy
- [ ] Respond to any late messages
- [ ] Get rest—it's a marathon, not a sprint

---

### DAYS 2-3: MOMENTUM

- [ ] Send daily email (new angle each day)
- [ ] Post 3-5 times per day on social media
- [ ] Share customer wins / testimonials
- [ ] Host live Q&A or webinar
- [ ] Create urgency ("Early bird ends in 48h")
- [ ] Reply to every comment / message
- [ ] Monitor competitors (what are they doing?)
- [ ] Double down on what's working

**Content Angles to Use:**
- "Why I created this" (origin story)
- "Here's what you get" (feature breakdown)
- "Customer spotlight" (testimonial)
- "Common objection answered" (FAQ)
- "Behind-the-scenes" (process, team)
- "Reminder: Early bird ends soon" (urgency)

---

### DAYS 4-5: PUSH TO CLOSE

- [ ] Send "Last chance for early bird" email
- [ ] Post countdown timers on social
- [ ] Offer last-minute bonus for fence-sitters
- [ ] Host final live session
- [ ] Create FOMO (show sales numbers, spots left)
- [ ] Share final testimonials
- [ ] Remind of guarantee / refund policy

**Urgency Tactics:**
- "Only 12 hours left for early bird pricing"
- "5 spots left" (if you're limiting availability)
- "Bonuses expire at midnight"
- "Price goes up tomorrow"

---

### DAYS 6-7: EVERGREEN TRANSITION

- [ ] Send "Last call" email (final chance)
- [ ] Close early bird pricing
- [ ] Transition to regular pricing
- [ ] Set up evergreen email sequence for future buyers
- [ ] Thank all customers
- [ ] Celebrate wins publicly
- [ ] Analyze launch performance

**MILESTONE:** ✅ Launch complete + Revenue generated + Customers onboarded

---

## 🔄 POST-LAUNCH PHASE (2 Weeks After)

### WEEK 1: DELIVER & DELIGHT

#### Customer Onboarding
- [ ] Send welcome email to all customers
- [ ] Deliver product / grant access immediately
- [ ] Send "How to get started" guide
- [ ] Check in with customers (are they stuck?)
- [ ] Create onboarding videos / tutorials
- [ ] Set up customer community (if applicable)

#### Support & Engagement
- [ ] Respond to all support requests within 24h
- [ ] Proactively reach out to quiet customers
- [ ] Ask for feedback (what's working, what's not)
- [ ] Fix bugs / issues immediately
- [ ] Share customer wins publicly (with permission)

#### Analyze Performance
- [ ] Review total revenue vs. goal
- [ ] Calculate conversion rate (visitors → buyers)
- [ ] Identify best-performing channels (email, social, ads)
- [ ] Review customer feedback themes
- [ ] Identify what to improve for next launch

| # Customers | ____ | ____ | |
| Conversion Rate | ___% | ___% | |
| Email Open Rate | ___% | ___% | |
| Best Channel | ____ | ____ | |
| ROI | ___% | ___% | |

---

### WEEK 2: OPTIMIZE & ITERATE

#### Improve the Offer
- [ ] Implement feedback from customers
- [ ] Fix any bugs or issues
- [ ] Add bonus content based on requests
- [ ] Improve onboarding based on common questions
- [ ] Create upsell / cross-sell offers

#### Set Up Evergreen Sales
- [ ] Create evergreen funnel (for ongoing sales)
- [ ] Set up retargeting ads for non-buyers
- [ ] Write follow-up sequences for abandoned carts
- [ ] Create limited-time offers for fence-sitters
- [ ] Plan next launch (when? what improvements?)

#### Document Learnings
- [ ] Write post-mortem (what worked, what didn't)
- [ ] Update launch checklist with new learnings
- [ ] Create SOPs (standard operating procedures) for next launch
- [ ] Train team on what worked
- [ ] Celebrate wins with team

**MILESTONE:** ✅ Customers happy + Feedback implemented + Evergreen running

## 💡 PRO LAUNCH TIPS

### 1. **Seed the Launch**
Start building hype 30 days before, not 3 days.

### 2. **Scarcity is Real**
Limited spots/bonuses work, but never fake scarcity. People can tell.

### 3. **Overdeliver on Day 1**
First impressions matter. Wow customers immediately.

### 4. **Engage Like Crazy**
Reply to EVERY comment/message during launch. Visibility = sales.

### 5. **Document Everything**
Film the process. Content gold + builds anticipation for next launch.

### 6. **Have a Plan B**
What if tech breaks? Payment fails? Competitor launches same day? Have backups.

### 7. **Rest Before Launch**
You'll be running on adrenaline. Start fully charged.

### 8. **Celebrate Small Wins**
First sale? Screenshot it. Share it. Momentum builds momentum.

## 🚨 COMMON LAUNCH MISTAKES TO AVOID

- [ ] ❌ Launching without validation
- [ ] ❌ No email list (launching to crickets)
- [ ] ❌ Perfectionism (waiting too long to launch)
- [ ] ❌ No urgency/scarcity (why buy now?)
- [ ] ❌ Not testing checkout process
- [ ] ❌ Ignoring mobile users
- [ ] ❌ Overcomplicating the offer
- [ ] ❌ Not following up with non-buyers
- [ ] ❌ Disappearing after launch (no post-launch nurture)
- [ ] ❌ Not learning from the launch

## ✅ FINAL PRE-LAUNCH CHECK

48 hours before launch, confirm:

- [ ] Sales page is live and tested
- [ ] Checkout works (test purchases completed)
- [ ] Email sequences are loaded and tested
- [ ] Social posts are scheduled
- [ ] Analytics/tracking is working
- [ ] Support system is ready
- [ ] You're mentally/physically prepared
- [ ] Team knows their roles
- [ ] Affiliates are briefed and ready
- [ ] You've cleared your calendar for launch week

**If any box is unchecked, delay the launch. Better to launch right than rush and fail.**

---

## 🎯 AFTER YOUR FIRST LAUNCH

Congratulations! You did it. Now:

1. **Take a break** (seriously, rest)
2. **Thank your customers** (personal messages)
3. **Analyze the data** (what worked?)
4. **Implement feedback** (make it better)
5. **Plan the next one** (launches get easier)

**Remember:** Your first launch won't be perfect. But done is better than perfect. Learn, iterate, improve.
